# orderbook_levels first-flush count — UI evidence

Generated by `tools/ux-orderbook-levels-capture.mjs`.

The delivered operator UI is the **process log** (`info!` once on count > 0,
`error!` once on count = 0 / `'type`). This feature **does not add
dashboard chrome**. `preview.html` is capture-only evidence of those locked
log lines in House tokens. It is **not** served by `fix_server`. Do not
copy it into `src/dashboard.html`.

The History tab is the existing kdb **snapshots** visual (anti-oracle for
`orderbook_levels`). Live / History stay anti-oracles. The kdb oracle is
still `fix_console` option 1 plus this process log. No count chip,
`/health`, or `/api/kdb*` was added (ADR-081 / ADR-097 / UI skip).

Do not treat these screenshots as a licence to add a kdb-counts panel.

**unchanged** in this polish. Operator-visible first-flush copy remains the
locked production lines:

- `info!("orderbook_levels count={} after first flush", n)`

- `error!("orderbook_levels count did not complete (timeout)")`
